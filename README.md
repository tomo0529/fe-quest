# FE QUEST セットアップ手順

基本情報技術者の勉強記録＆モチベアプリ（GitHub Pages ＋ Firebase）
ログインは Google アカウントだけ。新しいアカウント登録は不要。

## 1. Firebase プロジェクトを作る
1. https://console.firebase.google.com を開いて「プロジェクトを追加」
   - 名前は何でもOK（例：fe-quest）
   - Google アナリティクスは OFF でOK
2. 無料プラン（Spark）のままで大丈夫。クレジットカード登録は不要

## 2. ログイン（Authentication）
1. 左メニュー「構築 → Authentication → 始める」
2. 「Sign-in method」タブ → **Google** を有効にする（サポートメールは自分のを選ぶ）→ 保存
3. 「Settings」タブ → **承認済みドメイン** に `tomo0529.github.io` を追加

## 3. データベース（Firestore）
1. 左メニュー「構築 → Firestore Database → データベースを作成」
2. ロケーションは **asia-northeast1（東京）**、**本番環境モード** を選んで作成
3. 「ルール」タブを開いて、`firestore.rules` の中身をまるごと貼り付け
4. ルール内の `'CHANGE-ME'` を好きな **招待コード**（合言葉）に変えて「公開」

## 4. index.html に設定を入れる
1. 左上の ⚙ →「プロジェクトの設定」→「マイアプリ」でウェブ（`</>`）アイコンを押してアプリ登録
   （Firebase Hosting のチェックは不要）
2. 表示される `firebaseConfig = { ... }` の中身を、`index.html` の同じ部分に貼り替え

※ firebaseConfig の apiKey は公開前提の値。ルールで守ってるので HTML に書いてOK。

## 5. GitHub Pages
1. `tomo0529/fe-quest` に `index.html` を置く
2. Settings → Pages → Deploy from a branch / `main` / `/ (root)` → Save
3. 公開URL：`https://tomo0529.github.io/fe-quest/`

## 6. メンバー招待
- URL と **招待コード** を送る
- 「Googleでログイン → ユーザー名・試験日・招待コード入力」で参加
- 招待コードを知らない人は、Googleでログインできても中身を見たり書いたりできない
- 他メンバーに見えるのは **ユーザー名・試験日まで何日・連続日数・今日やったか** だけ（Googleの名前やメアドは見えない）

## 仕様メモ
- 日付の切り替えは日本時間 0:00
- 今日まだでも、昨日やってればストリーク継続中扱い（途切れそうなら警告が出る）
- 記録できるのは「今日」と「昨日」だけ（後から過去日を水増しできない）
- タグ（科目A / 科目B / 教科書）は任意。基本10XP ＋ タグ1つにつき5XP
- 100 XP ごとにレベルアップ、2レベルごとに称号とアイコンが変わる
- ヒートマップは2タグ以上の日が明るい緑

## うまくいかない時
- 「承認済みドメインに入ってない」→ 手順2-3を確認
- 「招待コードが違う」→ ルールの招待コードと入力が一致してるか、ルールを「公開」したか確認
- 「権限がない」→ ルールが貼れてるか確認
